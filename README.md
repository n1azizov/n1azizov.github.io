# Nadir Azizov — Portfolio

Personal portfolio for Nadir Azizov, Computer Science student at the French-Azerbaijani University (UFAZ).

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server. The site has no package dependencies or build step.

## Deploy

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes the repository root to GitHub Pages on each push to `main` and on manual workflow runs. The expected Pages repository is `n1azizov/n1azizov.github.io`.

The workflow requires GitHub Pages to use **GitHub Actions** as its build and deployment source. Once that source is selected and the workflow completes, the site is served at `https://n1azizov.github.io/`.
